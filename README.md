# Explainable-Hybrid-AI-with-Exogenous-Variables-for-DI
Code for "Explainable Hybrid AI with Exogenous Variables for Three-hourly Discomfort Index Forecasting in a Dense Tropical City" (Dhaka, Bangladesh). Two-stage hybrid models (e.g. GRUX-SARIMA, SARIMAX-GRU), 82 configurations, benchmark tests, conformal intervals and SHAP explanations.
